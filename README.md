# Gerber -> ЛУТ и ЧПУ

Программа для подготовки печатных плат из EasyEDA Pro к домашнему изготовлению:

- раскладка нескольких плат на заготовке текстолита (копии, массив, поворот на любой угол, базовые отверстия);
- **PDF 1:1 для ЛУТ** (лазерно-утюжная технология): верх зеркально, низ как есть, оба слоя на одном листе с линиями сгиба для «конверта», оси координат, кресты совмещения и линия отреза;
- **DXF / SVG для фрезеровки и сверловки на ЧПУ** (проверено с Vectric Aspire 12.5): отдельный файл на каждое сверло из вашего набора, контур платы под фрезу, пазы - фрезой или рядом отверстий, начало координат в углу заготовки или в базовом отверстии.

## Скачать

Последняя версия - на странице **[Releases](../../releases/latest)**: файл `GerberLUT-CNC-<версия>-win64.zip`.

## Установка

1. Скачайте архив и распакуйте его в любую папку (Windows 10/11, 64 бит).
2. Запустите `GerberLUT-CNC.exe`. Python и другие программы ставить не нужно.

`GerberLUT-CNC.exe` работает только вместе с папкой `_internal` рядом с ним - переносите папку целиком.

Если Windows SmartScreen покажет «Система Windows защитила ваш компьютер», нажмите **«Подробнее» -> «Выполнить в любом случае»**: у программы нет платной цифровой подписи.

## Как пользоваться

1. `Файл -> Импорт Gerber ZIP` (Ctrl+I) - выберите ZIP, который выгружает EasyEDA Pro.
2. Расставьте платы на заготовке, при необходимости добавьте базовые отверстия (Ctrl+1). Ctrl+B - заготовка минимального размера по содержимому.
3. Ctrl+P - PDF для ЛУТ. Печатайте **в масштабе 100%**, без «подогнать по размеру страницы», и проверьте линейкой риски осей.
4. Ctrl+E - папка с DXF/SVG для ЧПУ. В Aspire размер задания = размер заготовки, начало XY - там же, где 0,0 в файле (см. `info.txt` в папке экспорта).

Все горячие клавиши - F1 в программе, описание и версии - `Справка -> О программе`.
